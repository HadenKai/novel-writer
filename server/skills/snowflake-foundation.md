这是规划规则，不是正文腔调。使用时只把与当前任务有关的部分转化为可执行决定。

1. 核心种子：用一句话写清“主角遭遇什么事件，必须采取什么行动，否则会付出什么后果；更大的隐藏危机是什么”。必须同时包含显性冲突、主角驱动力和世界矛盾。
2. 角色弧光：每个核心角色都记录“表面追求、深层渴望、灵魂需求、秘密/弱点、初始状态→触发事件→认知失调→蜕变节点→当前状态”。角色的选择必须受动机推动，不用旁白替角色解释一切。
3. 世界构建矩阵：分别检查物理/空间与规则、社会/权力与资源、隐喻/反复意象三个维度；每个维度至少提供一个能影响角色决策的动态因素。
4. 三幕悬念：开端打破日常并埋下异常征兆；中段让主线与副线交叉，安排双重压力、虚假胜利和认知颠覆；后段让代价显现并回收主要伏笔。每一阶段都要记录下一步可验证的事件。
5. 章节落地：本章只执行当前阶段的任务，不提前消费后期秘密；结尾留下具体可感的未完成动作、异常信息或新的选择。

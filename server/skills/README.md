# 内置写作 Skill

这些 Markdown Skill 随 NovelWriter 一起发布，采用本项目现有的 frontmatter 格式。内容是对公开仓库方法论的提炼移植，不复制其 Python/Node 实现。

| Skill | 主要来源 | 作用 |
|---|---|---|
| `editor-novelist` | 本项目原创 | 对话内写作宪法：黄金法则 500~800 字/节、以成书章节为前文基准、拆书建立风格档案、正负向写作约束（对话系统提示词自动注入） |
| `snowflake-foundation` | AI_NovelGenerator（MIT） | 雪花写作法、角色弧光、世界构建矩阵、三幕悬念 |
| `pipeline-12-stage` | Casting-Workflow（以仓库声明的许可证为准） | 12 阶段创作流水线和阶段交接 |
| `continuity-journal` | AI_NovelGenerator、novelops、novel-writer-skills | 章节摘要、人物状态、关系、伏笔和章末钩子 |
| `anti-ai-natural-chinese` | Casting-Workflow、novelops（MIT） | 中文原生、反模板、生成后质检 |
| `consistency-audit` | AI_NovelGenerator、novelops（MIT） | 角色、设定、时间线、关系、伏笔一致性 |
| `pov-pacing-check` | novelops（MIT）、novel-writer-skills（MIT） | 视角边界、历史事实检索、节奏检查 |
| `genre-webnovel` | AI_Gen_Novel（MIT）、novel-writer-skills（MIT） | 类型知识、网文节拍、读者承诺 |
| `style-direction` | AI_Gen_Novel（MIT） | 风格选择、风格冲突隔离、风格管理 |
| `web-research-protocol` | GPT Researcher（MIT）、STORM（MIT）、Anthropic web-research（公开提示词） | 子问题拆分、多视角检索、读原文、交叉验证、带引用作答 |
| `source-verification` | GPT Researcher（MIT）、STORM（MIT） | 来源分级、时效检查、冲突标注、四档置信度 |

许可说明：本项目只把上述仓库公开描述和提示词中可归纳的创作方法转写为独立规则。若上游仓库的许可证或内容发生变化，应在更新这些 Skill 前重新核对许可证。

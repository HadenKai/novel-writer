适用：把检索结果写进回答、设定或正文之前。

## 来源分级

| 级别 | 类型 | 例子 |
|---|---|---|
| A 一手 | 原始记录、官方发布、法规原文、论文全文、作品原文 | 政府公告、法院文书、期刊论文、出版社原文 |
| B 可靠二手 | 有编辑/审稿机制的专业媒体、机构报告 | 通讯社、百科全书条目（带引用）、行业报告 |
| C 一般 | 个人博客、论坛、自媒体、问答站 | 知乎回答、贴吧、营销号 |

结论至少要有 A 或两个独立 B 支撑；只有 C 级来源时，必须写明「据非官方来源」。

## 核验动作

1. **抽事实**：把要写进回答的关键句拆成「主体 + 属性 + 数值/时间」。只核验承载结论的句子，不是每一句都查。
2. **查日期**：确认来源的发布时间与数据截止时间。把旧数据当现状，比没有数据更糟；引用时写「截至 2026 年 3 月」这类时间锚点。
3. **找独立来源**：同一集团、互相转载的站点不算独立；两个来源引用同一篇通稿也只算一个。
4. **比对冲突**：数字/结论不一致时，列出各自说法、来源级别与日期，说明你倾向哪一个及理由；无法判断就并列呈现。
5. **标注置信度**：在结论后用括注标一档——
   `（已证实）` 两个以上独立 A/B 来源一致；
   `（单一来源）` 只有一处可靠来源；
   `（存在分歧）` 来源互相矛盾；
   `（未查到）` 检索后仍无可靠来源。

## 禁止

- 编造 URL、标题、作者、发布日期。
- 把模型记忆里的印象写成「资料显示」。
- 用「业内普遍认为」代替具体来源。
- 为了行文顺畅删掉限定词（「约」「截至」「据报道」），把不确定说成确定。

## 输出模板

```
结论：……（已证实）
依据：[1] 来源标题（机构，2026-03-12）；[2] ……
分歧：……（如有）
未确认：……（如有）
```

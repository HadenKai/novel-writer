# 小说工坊 · 界面设计方案（v2）

> **历史文档**：令牌与配色已由 `docs/ink-design.md`（墨金，2026-10-31）取代；本文保留的是「线条预算、尺度收敛」等诊断思路。

> 目标：回答「为什么整个项目的 UI 说不出哪里怪」，并把答案变成可执行的规范。
> 本文分三部分：**诊断（带数据）→ 设计原则 → 已落地 / 待落地**。

## 一、诊断：不是某一块丑，是「尺度」失控

对 `src/**/*.tsx` 做了一次全量统计，问题全部可量化：

| #   | 问题             | 数据                                                                                                          | 为什么「说不出但感觉得到」                                                       |
| --- | ---------------- | ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| 1   | **圆角尺度失控** | 190 处内联圆角、**11 种值**（3~16px）；令牌只定义了 5/7/9/12/18，**8px 用了 72 次而令牌里根本没有 8**         | 相邻组件的圆角差 1~2px，眼睛能察觉「不齐」却无法命名——这是最典型的「隐性不协调」 |
| 2   | **字号尺度失控** | **17 种字号**：10 / 10.5 / 11 / 11.5 / 12 / 12.5 / 13 / 13.5……（12px×99、11px×67、10.5px×16）                 | 层级是「抖动」出来的不是「分级」出来的，整页看起来毛糙                           |
| 3   | **线条密度**     | **53 处整圈框线 + 31 处 ring + 34 处分割线 ≈ 118 条可见线**；列表项、chip、输入框、按钮全是一圈框，框里还套框 | 你说的「线条有点多」                                                             |
| 4   | **卡片装饰过载** | `.card-surface` = 渐变背景 + 内嵌白色高光 + 描边 + 阴影，**四层装饰叠一张卡**                                 | 每张卡都「厚」，卡片一多整页就闷                                                 |
| 5   | **色温错配**     | 滚动条是**冷蓝灰 `#c8c8cf`**，而全站是暖纸色                                                                  | 色温打架，视觉上「哪里不对劲」但说不出                                           |
| 6   | **氛围光叠加**   | `body` 有 `--bg-glow`，`.studio-page::before` 又加一层金色光晕                                                | 每个页面顶部都泛着一层说不清的色带                                               |

**结论**：令牌系统本身是健康的，坏在**执行层没有约束**——内联值随意取、每处自己画框。
所以修法不是重画某一屏，而是把尺度钉死、把线条预算收紧。

## 二、设计原则（四条，后续所有界面改动以此为准）

1. **一条线只画一次。**
   线条预算：每个区块最多一条分隔线；列表项靠**底色**区分（hover / 选中），不画框；
   分割线一律 `--line-soft`，不用 `--line`。
2. **表面只有三级。**
   画布 `--bg` → 面板 `--panel` → 内嵌 `--panel2`。卡片是**纯色**表面，层级交给阴影，
   禁止渐变与内嵌高光。强调色（陶土红）只做「点」（按钮、选中态、小标记），不做「线」、不做「面」。
3. **一套尺度，不许内联新值。**
   圆角 5 档：`--r-xs 5 / --r-sm 7 / --r-md 9 / --r-lg 12 / --r-xl 18`；
   正文 6 档：10 / 11 / 12 / 13 / 14（标题 16 / 20 / 22 另算）。内联出现尺度外的值即视为 bug。
4. **装饰做减法，信息做加法。**
   同一元素上「描边 + 阴影 + 渐变 + 高光」最多出现两样。空白本身就是分隔，优先用留白而不是画线。

## 三、已落地（第一刀：令牌与共享类层，一处改全局生效）

| ------------------ | -------------------------------------------------------------------- | ---------------------------------------------------------- |

## 四、待落地（第二刀：页级去框，需要逐屏过）

按收益排序，每屏改完都应肉眼比对一次：

1. **列表项去框**（收益最大）：书架卡、会话列表、章节列表、回收站条目——去掉 `ring-1`，
   选中态用 `--panel2` 底色 + 左侧 2px 强调条。
2. **表单去框**：设置页的每组字段外面还有一层 `card-surface`，字段输入框又有一圈——去掉外层，留输入框。
3. **工具条降对比**：成书 / 精修页顶部工具条按钮改纯文本 + hover 底色（沿用管家页的做法）。
4. **弹层统一**：`ModalShell` 与页面内自绘弹窗（Shelf / Settings / Library 共 5 处）收敛到同一套圆角与阴影。
5. **深色主题复查**：`--line` 降档后深色下对比更低，需确认输入框在 `--panel2` 上仍可辨。

## 五、验收口径

- 全站内联圆角值 ⊆ {3, 4, 5, 7, 9, 12, 18}；正文字号 ⊆ {10, 11, 12, 13, 14}。
- 任一屏幕内可见的框线 ≤ 3 条（不含输入框与按钮自身的描边）。
- 卡片表面为纯色；渐变只允许出现在 `--bg-glow` 与稿纸底色。
- 滚动条、分割线、描边三者的色相一致（暖纸系）。

## 六、两套主题整体重调（浅色「恶心」/ 深色「冷硬」）

先量化，再动手。对比度用 WCAG 相对亮度公式实算：

### 浅色为什么「恶心」

| 病因                       | 实测数据                                                                                   |
| -------------------------- | ------------------------------------------------------------------------------------------ |
| **四层表面几乎同色**       | 画布 vs 卡片分离度仅 **1.11**、vs 内嵌 **1.05**、vs 侧栏 **1.09** —— 全靠那 118 条描边区分 |
| **弱化文字大面积发灰发虚** | `--text-faint #a49a8d` 对白卡只有 **2.72:1**（AA 需 4.5:1）                                |
| **底色黄奶油偏重**         | `#f6f1e9 / #f2ece2 / #eee7dc` 全是黄调，再叠两层暖色光晕 → 泛黄发腻                        |

### 深色为什么「冷硬」

| 病因               | 实测数据                                                          |
| ------------------ | ----------------------------------------------------------------- |
| **文字层级拉不开** | 次要文字 **8.89:1**，正文 15.03:1 —— 差距太小，所有文字都在「喊」 |
| **阴影是纯黑重影** | α 0.35 ~ 0.70，压在深棕底上生硬                                   |
| **同一屏两种温度** | 画布 RGB(23,23,20) 偏绿灰，卡片 RGB(41,39,32) 偏棕                |

### 重调后的令牌

| 令牌             | 浅色 旧 → 新                                       | 深色 旧 → 新                                       |
| ---------------- | -------------------------------------------------- | -------------------------------------------------- |
| `--bg`           | `#f6f1e9` → **`#f2ede5`**（去黄，暖灰纸）          | `#171714` → **`#1b1915`**（统一到暖棕）            |
| `--rail`         | `#eee7dc` → **`#eae3d8`**                          | `#201f1b` → **`#23201a`**                          |
| `--panel`        | `#fffdf8` → **`#ffffff`**（提到纯白，靠亮度分层）  | `#292720` → **`#2b2822`**                          |
| `--panel2`       | `#f2ece2` → **`#eae4d9`**                          | `#343027` → **`#36322a`**                          |
| `--line`         | `#ded4c7` → **`#e0d8ca`**                          | `#484239` → **`#453f34`**                          |
| `--text`         | `#29251f` → **`#26221c`**                          | `#f1eadf` → **`#ebe4d7`**                          |
| `--text-dim`     | `#71675b` → **`#6d6458`**（5.45 → **5.81**）       | `#c0b5a5` → **`#a79c8b`**（8.89 → **6.50**）       |

### 同时落地的一处去线条

**次级按钮 `.btn--ghost` 去描边**（改靠填充区分）——幽灵按钮遍布全站，这是「线条多」的**最大单一来源**，
一处改动全站生效。

### 验收（调后实测）

- 浅色：弱化文字 **4.74:1** ✅、次要 **5.81:1** ✅、卡片/画布分离度 **1.17**（原 1.11）
- 深色：次要文字 **6.50:1**（与正文 13.88 拉开层级）、弱化 **4.60:1** ✅、阴影整体减重约 25%
- 两套主题表面各归一档温度：浅色暖灰纸 + 纯白卡片；深色全暖棕

## 七、去「肉色」+ 模式切换动效

### 「肉色」的来源（定位过程）

用户反馈浅色整体发「肉色」。排查结论：**不是中性色本身，而是盖在画布上的那层陶土红光晕**——
`--bg-glow` 的第一个 radial 是 `rgba(184, 92, 66, 0.05)`（正是主色陶土红），半径 32rem，
几乎罩住整个视口，等于给整页刷了一层极淡的肤色；再叠加黄奶油底色（色度约 27%），读感就是「肉色」。

### 修正

| 项                | 旧 → 新                                                                                                                            | 说明                                                    |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| `--bg-glow`（浅） | `rgba(184,92,66,.05)` / `rgba(202,165,117,.055)` → **中性暖灰 `rgba(140,128,112,.04)`**                                            | 拿掉带色相的光晕，肉色感的主因                          |
| `--bg-glow`（深） | 陶土红 / 棕 → **中性 `rgba(255,242,224,.03)`**                                                                                     | 同上                                                    |
| 浅色中性色        | `--bg #f2ede5→#f4f2ed`、`--rail #eae3d8→#edeae3`、`--panel2 #eae4d9→#eceae4`、`--panel3 #ded6c8→#e0ddd5`、`--line #e0d8ca→#e1ded6` | **色度从约 27% 降到约 14%**，从「黄奶油」回到「暖灰纸」 |
| 深色中性色        | `--bg #1b1915→#1b1a17`、`--rail #23201a→#232220`、`--panel #2b2822→#2b2a26` 等                                                     | 与浅色同一套降色度策略                                  |

### 模式切换动效（精修页）

用户反馈「切换功能为什么没有动效」。原因：四个模式按钮虽有 `transition`，但切换只带来一次
150ms 的底色微变，几乎不可感知；而下方的模式说明块是**条件渲染直接换内容**，没有入场。

修正：

- 按钮：`transition-all duration-200 ease-[var(--ease)] active:scale-[0.97]` —— 按下有物理反馈
- 模式内容块：新增 `.mode-fade`（180ms，上移 3px + 淡入），随条件渲染挂载时播一次
- 尊重 `prefers-reduced-motion`：动画直接关闭

> 动效的分寸：**要让人「感觉到变化」，不能让人「等它动完」**。3px / 180ms 是上限。

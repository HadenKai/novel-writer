# 小说工坊：正文中心重构

## 产品定位

本地优先的长篇创作工作台。打开软件的第一件事应是回到作品，而不是配置模型。AI 是编辑助手，不是页面组织原则。

## 信息架构

- 全局：创作桌、素材、知识库、设置。全局导航只出现一次。
- 作品：正文为默认入口；规划（章节大纲）、设定、审校、预览保留明确入口。
- 写作：章节目录 / 正文 / 上下文检查器；目录换章直接进入正文，不经过章节卡片中转。
- 恢复上一章通过稳定 oid 记录；若章节被移除，回落到现有章节或明确空状态。
- 没有模型也能手写；只有调用 AI 时才要求选择模型。

## 视觉约束

中性纸白和石墨深色，单一低饱和绿色强调。正文采用中文衬线字体，工具区采用系统无衬线。弱化卡片阴影、渐变和无意义英文装饰。每屏一个主要动作，其余操作收敛为次级按钮。键盘焦点清晰，窄窗口保持可操作。

## 行为与状态

保存状态区分本地草稿、提交中、已落盘、失败。离开编辑器前保护未提交修改；后台任务不静默覆盖正在编辑的内容。AI 修改以预览、采纳、撤销为准，不直接等同于发布。数据恢复先完整校验；回收站恢复失败保留原件。

## 交付顺序

1. 重做视觉基础、全局导航和继续创作首页。
2. 正文中心三栏工作台、稳定章节定位和无模型手写入口。
3. 衔接 AI、规划和资料；审查保存竞争和离页保护。
4. 修复数据恢复失败路径并补测试。
5. 构建、回归测试和可用的实际界面验证。

## 本轮已落地与验证

- 首页继续创作、次级写作记录、精简全局导航和正文默认入口。
- 三栏正文工作台、稳定 oid 位置记忆、资料检查器、窄窗口布局。
- 无模型新建空章，已有大纲优先复用，并发创建不重号。
- 本地草稿缓存、关窗提醒、服务端乐观冲突校验、最新原稿核对入口。
- 审校生成候选稿不改正文，原稿与建议稿并列对照，显式采纳留存历史；原稿变化返回冲突。
- 回收站恢复先复制，全部成功后再删除原件；故障测试验证原件保留。
- TypeScript 和生产构建通过；完整回归测试 127 项通过。
- Electron 独立临时数据环境实测：1440 / 1000 / 600 外窗宽度均无页面横向溢出，正文编辑器及章节目录挂载成功，审校提示可见。
- 当前工具模型未声明图像输入，截图已生成但未进行人工式视觉审阅；DOM 检查不代替审美验收。

## 第二轮追加（规划板与数据保护）

- 章节规划改为「左目录 + 右详情」规划板，替代每章一张大卡的长列表；支持搜索、逐章框架与专属指令。
- 规划板选中项以 oid 锚定：上移/下移/插入/删除后仍停在原来那一章（此前的锚点写法会把主动换章误判为位移）。
- 备份升级到 v3：纳入素材与草稿、写作偏好、码字统计、站点名，恢复时一并还原；模型密钥仍不导出。
- 恢复流程加三层保护：整批预检（损坏的第二本不会写坏第一本）、文件级回滚点（写入中途失败自动回滚）、有保存或 AI 任务运行时拒绝恢复。
- 无主恢复副本从「启动即删」改为隔离到 recovery-orphans，正文不再被永久清除。
- 自动备份每日定时任务此前只做清扫、不产出备份，已修正为同时生成备份；清理时一并清掉同名 .bak。
- 全站文案与新导航对齐（本书管家 → 与 AI 讨论、精修 → 审校、恢复说明改为按 ID 合并并标注不含项）。
- 真实 Electron 渲染巡检 12 条路由：全部正常挂载、无横向溢出、无空白页，控制台仅有既有 CSP meta 提示。
- 回归测试 129 项全部通过。

## 剩余工作

候选稿跨重启保留（当前建议存在内存任务里，重启即失效）、AI 失败与截断的界面文案统一、草稿冲突交互的自动化测试，以及素材库、知识库、设置三页更深层的布局重构。当前已完成核心创作链路与规划板，不宣称全部界面均已重做。

## 保留与边界

保留数据格式与原有 API，优先复用已验证能力。先建立源代码快照；用户书稿、历史备份、安装产物均不作为清理对象。不会把改动后的构建检查称为浏览器验证。

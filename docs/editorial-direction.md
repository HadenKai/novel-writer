## 方向

**编辑台 · 暖纸墨色**：长期使用的写作桌面，不是营销页。

- 目的：打开软件先回到作品与当前章节，工具只在需要时出现。
- 受众：每天重复写作的单一作者，先扫作品名、进度、正文，再找操作。
- 语气：editorial / refined / utilitarian / calm。
- 记忆点：朱砂印章式应用标记、编号章节标题、带页眉的稿纸正文。
- 约束：React + Vite + Tailwind；沿用现有路由、数据、API 与组件；桌面优先，600px 可操作。

## 色彩

| 语义                | 浅色      | 深色      |
| ------------------- | --------- | --------- |
| 画布 `--bg`         | `#F3F0E8` | `#1B1915` |
| 侧栏 `--rail`       | `#EBE5DA` | `#221F1A` |
| 面板 `--panel`      | `#FFFDF8` | `#2A261F` |
| 内嵌 `--panel2`     | `#F4EFE5` | `#342F26` |
| 文字 `--text`       | `#26221C` | `#F0E8DA` |
| 次要 `--text-dim`   | `#5E574C` | `#C2B6A3` |
| 弱化 `--text-faint` | `#766D60` | `#A29784` |
| 强调 `--gold`       | `#8F4A3A` | `#D19A86` |
| 成功/本地 `--jade`  | `#3D6B52` | `#9CC3A9` |
| 草稿/提醒 `--amber` | `#8A6528` | `#D8B77A` |

`--gold` 是历史令牌名，语义是低饱和朱砂强调色，不要按“金色”理解，也不要大范围改名。

## 排版

- 工具与表单：`var(--font-ui)`，系统无衬线。
- 页面标题与书籍标题：`var(--font-display)`，衬线展示。
- 小说正文：`var(--font-reading)`，正文衬线；正文最小 13px，长文默认 17px / 行高 2。
- 辅助文字不低于 11px；`--text-faint` 在画布和面板上均满足 AA。

## 形状与线条

- 圆角：4 / 6 / 8 / 10 / 14；不再使用 16px 以上卡片圆角。
- 每个区块最多一条分隔线；列表靠底色和左侧标记区分，不画整圈边框。
- 强调色只做“点、短线、下划线、主按钮”，不做大面积色块。
- 不使用紫色渐变、装饰光斑、嵌套卡片、过大的圆角或重阴影。

## 页面结构

- 全局壳：224px 侧栏；52px 顶部工具栏；印章标记 + “长篇创作台”副标题。
- 作品库：编号章节标题（01 最近编辑 / 02 全部作品）、继续写作卡、搜索与网格。
- 作品工作台：固定五个工作区页签，编辑式下划线指示当前区；正文三栏，目录/资料可收起。
- 写作模式：正文页签下划线，章节目录选中态使用左侧 2px 朱砂短线；深色使用暖黑稿纸。
- 协作页：规划板、审校候选稿、导出预览沿用同一套纸白面板和细线，不再局部覆盖颜色。

## 动效体系

- **路由转场**：统一走浏览器 View Transitions（`src/lib/motion.ts`）。旧页 180ms 缩小淡出，新页 340ms 上移淡入并错开 40ms，形成接力；只给内容区命名 `view-transition-name`，侧栏与工具栏保持静止。
- **降级**：不支持 View Transitions 的内核退回 CSS 入场动画；系统开启「减少动态效果」时全部转场降级为直接切换。
- **列表错峰**：卡片使用 `.stagger-item` + `--stagger-index`，逐项 45ms 浮现。
- **骨架屏**：加载态用 `.skeleton` 微光，结构尺寸不跳动。
- **局部反馈**：卡片悬停轻微上浮 + 封面放大；按钮按下统一收缩到 0.97；保存状态点用呼吸光圈；收起资料栏时列宽平滑过渡。
- **原则**：动效只用于说明「从哪来到哪去」，不做装饰性循环动画。

## 布局层级

- 顶部只有 **一条** 工具栏（52px）：侧栏开关 / 书名 → 工作区页签 → 搜索 / 主题 / 窗口按钮。作品工作区的五个页签并入此处，页面内不再另起横栏。
- 写作页因此从「三层横条」压缩为「两层」：顶部工具栏 + 编辑器工具栏。
- 作品库自上而下：页头 → 01 继续写作（整行主入口，含封面、进度与动作）→ 02 全部作品（搜索 / 排序 / 网格）→ 码字统计（常驻可见）→ 页脚工具条。
- 不再出现「三张并排小卡 + 右侧大片空白」的结构；统计不再藏在折叠块里。

- 1440×900、1000×900、600×900 核心路由无横向溢出。
- 浅色/深色均使用语义令牌；控制台无资源 404、无限转场中止。

# 小说工坊 · 墨金界面规范

> 2026-10-31 起的前端方向，取代 `editorial-direction.md` 的「暖纸墨色」。
> 参考稿：`E:\画布\mockups\novel-ui\`（00 视觉系统板、01 书架、02 设定、03 规划、04 正文、05 审校、06 研讨、07 资料库、08 素材、09 导出、10 组件）。
> 参考稿是概念图：对齐它的布局、层级、材质、配色与字体，不逐像素复刻，也不照搬图里的假数据。

## 方向

东方暗黑文人风：深夜书房、墨与宣纸、鎏金细节。长期写作的桌面工具，安静、贵气、有文学性。

- 深色「墨黑」是默认主题；浅色「宣纸」是日间版本，两套共用同一组语义令牌。
- 正文永远写在宣纸稿面上。深色主题下就是「一张纸放在深色书桌上」。
- 鎏金只用于 1px 细线、选中态、主按钮与关键数字；朱砂只用于印章与危险操作；竹青只用于成功与本地状态。
- 不使用：霓虹、紫蓝渐变、玻璃拟态、卡通插画、3D 透视、重阴影、大面积金色色块。

## 排版

- 页面标题：宋体 26–36px，字重 700，字距 0.04em。
- 区块标题：宋体 16–18px，字重 650，前置 ◇ 或 ┃。
- 界面文字：黑体 13–14px；辅助文字 12px；最小 11px。
- 正文：宋体 17px，行高 2，写在宣纸上。
- 数字：统计大数字用 `.ink-num`；字数、时间等小数字用 `tabular-nums`。

## 布局

- 外壳：侧栏 232px，收起后是 72px 图标栏（图标下带小字）；顶栏 56px。作品工作区的五个页签（正文 / 规划 / 设定 / 审校 / 导出）放在顶栏，当前区用鎏金下划线标出。
- 三栏工作区：左栏 216–260px（目录、子页签、会话），右栏 280–320px（AI 抽屉、设定速览、阅读设置）。宽度不足时右栏先改为覆盖层，再窄时左栏也改为覆盖层。
- 每屏只有一个鎏金主操作，其余用 ghost、outline 或文字按钮。

## 模型选择器与 agent 对话

- **模型选择器**（`components/ModelSelect.tsx`）：「中转站 → 模型」两级面板，底部是思考强度滑杆与「管理模型」。表单里用 `variant="field"`，输入区工具条里用 `variant="pill"`。徽标只表达配置里确有的信息（默认 / 本地 / 上下文 / 接入协议），不写臆造的能力标签。
- **思考强度**是模型自身的配置（与「模型设置」的分段按钮同一字段），档位定义在 `lib/thinking.ts`，必须与 `server/models.mjs` 的白名单一致。改动后广播 `writer-model-updated`，其它页面的 `useModels` 就地合并。只有主对话页开 `hotkey`（Ctrl+T 循环档位）。
- **管家回复**用 `components/Markdown.tsx` 渲染（只输出 React 元素，不拼 HTML）；动作记录写成工具调用行（`.tool-call`，左侧色条 = 动作类别）；运行中显示阶段 + 计时，思考过程可折叠；回复进行中按 Enter 排队，本轮正常结束后自动发出。
- **资料库问答**复用同一套对话组件（`Composer` + 消息样式 + 模型胶囊），只在 `pages/kb-qa.css` 里补这一栏的头部、引用来源与窄栏适配。模型选择放在输入框工具条里、发送键旁边，不要再做成输入框下面一整行的表单下拉。回答里的 `[n]` 渲染成引用角标，与下方「引用来源」的序号一一对应。

## 按钮「烫金墨块」

2026-11-01 用本机生图出了四套按钮设计板（哑光鎏金 / 烫金墨块 / 发丝金线 / 描金漆器），选定「烫金墨块」：主按钮不是整块金条，而是墨块底 + 鎏金细框 + 金字，悬停金线提亮、内里泛一层淡金；次级是几乎无框的炭黑块；描边是透明底金线；危险是朱砂墨块；胶囊、发送键、模型胶囊都用同一套。颜色只从 `--gilt-top / --gilt-bottom / --gilt-line / --gilt-text / --gilt-glow` 取，深色、浅色、`.ink-on-paper` 各算一份，新按钮不要再写 `var(--gold-hi) → var(--gold-lo)` 的金条渐变。

滚动条只用 `::-webkit-scrollbar` 定制，**不要写 `scrollbar-width` / `scrollbar-color`**：Chromium 121+ 看到这两个标准属性就会忽略 webkit 定制，退回带上下箭头的系统滚动条。

## 水墨插画素材

`src/assets/ink-*.jpg` 是本机生图的水墨画转成的**亮度遮罩**：墨 → 白（不透明）、纸 → 黑（透明）。用法是 `background: <主题色>; mask: url(...) luminance`，同一张图在深色下是金线、浅色下是褐墨。新素材按同样方式处理：灰度取反并拉对比，让宣纸与淡雾压到全黑，JPEG 质量 84 左右。

## 动效

沿用 `editorial-direction.md` 的动效体系：View Transitions 路由转场、列表错峰、骨架微光、悬停轻抬、按下收缩。动效只交代空间关系，不做装饰性循环；`prefers-reduced-motion` 下全部关闭。

页面转场的性能约束（`src/lib/motion.ts`，2026-11-01 实测后定下）：

- 只给内容区起 `view-transition-name`（`app-content`），`:root` 设为 `none`。侧栏、工具栏不截图、不参与转场，切页时一直是真实元素。
- `::view-transition { pointer-events: none }`：动画播放期间的点击直接落到页面上，不会被转场层吞掉。
- 更新回调里用 `flushSync` 同步提交新页面，不要再「等两帧」——转场期间 rAF 被挂起，等帧只会白等兜底定时器。
- 转场关键帧只动 `opacity` / `transform`，不要用 `filter: blur`。
- 自动适配：低配机器（≤2 核或 ≤2GB）起步就用 lite 档（不截图，内容区 CSS 进场）；连续 3 次截图开销超过 120ms 也自动降到 lite。

## 验收

- 1440×900、1000×900、600×900 无横向溢出；深浅两套主题都要检查。
- 文字对比度 ≥ 4.5:1；键盘焦点可见（2px 鎏金外框）。
- `npm run verify` 通过。
